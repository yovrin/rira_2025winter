# 学習状況チェックシステム（Study progress check）ZEN大学用

パソコンのブラウザで動作する **ZEN大学学習状況チェックシステム** です。  

---
## 使用言語
言語：Python3.12.3
## フレームワーク
Flask
## データベース
Sqlite

---

## 利用手順
URL:
 https://zen-tool.com/
## １．
 「新規ユーザ登録はこちら」よりユーザ、パスワード作成
 (新規ユーザ登録しなくても、ユーザ：test1　パスワード：test1　でログインできます。)
## ２．
 ログイン
## ３．
 左上「更新画面へ」より取得済の科目を登録
## ４．
 一覧でどの科目を取得したか確認できる。（済マーク有）
## ５．
 左上「卒業要件チェック」で、卒業要件チェックが行える。
## ６．
 左上「CAのアドバイス」で、CAからのアドバイス動画が見れます。
(ずんだもんの音声流れます。（ライセンス：クレジット表記あり）)
## ７．
 左上「絶対押さないで」ボタンを押すと……


## 特徴

- **自分の履修状況が直感的に分かります。**
- **卒業要件のチェックができます。**
- **危険ボタン**：「絶対押さないで」を押すと......
